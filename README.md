# Chat-Pro

Локальное демо-приложение: мессенджер с пользователями, группами, комьюнити, отзывами, звёздами, премиумом, акциями, статусами и админкой.

## Как запустить

В терминале из папки проекта:

```bash
cd /Users/Shared
python3 server.py
```

Откройте в браузере:

- приложение: <http://localhost:8000>
- админка: <http://localhost:8000/admin>

Ключ админки по умолчанию:

```text
admin123
```

Сменить ключ можно так:

```bash
MINIGRAM_ADMIN_KEY=мой_ключ python3 server.py
```

## Что добавлено

- регистрация с подтверждением e-mail и телефона, вход, восстановление пароля кодом и сохранённые аккаунты при выходе;
- личные чаты и «Избранное»;
- группы и комьюнити/беседы;
- счётчики подписчиков, просмотров и реакций;
- настройка видимости счётчиков на уровне группы через данные чата;
- отзывы по ссылкам на страницы ВК/ТГ/сайтов: положительный `+1`, отрицательный `-1`, комментарий необязателен;
- связки для отзывов: другие ссылки, имена, названия;
- внутренняя валюта — звёзды;
- донаты звёздами на пользователей и посты;
- покупка премиума за звёзды;
- покупка звёзд через ЮKassa после настройки платёжного кабинета;
- дневная/ночная тема и личный цвет своих диалогов;
- аудио- и видеозвонки в личных чатах: браузер запрашивает доступ к микрофону и камере;
- кнопка показа/скрытия пароля при входе и регистрации;
- управление звонком: отключение микрофона, пауза и гудки при ожидании ответа;
- установка как PWA-приложение на iOS и Android с иконкой;
- глобальный поиск по пользователям, чатам, сообщениям и профильным постам;
- загрузка пользовательских аватаров;
- профильные посты и сторис на 24 часа;
- актуальные акции с наградами;
- статусы-иконки с условиями и наградами;
- рекомендованные группы из админки;
- уровни аккаунта с серверными лимитами, покупкой следующего уровня за звёзды и наградами; лимит баланса звёзд и количество сохранённых входов также применяются;
- импорт новых публикаций из внешнего Telegram-канала через Telegram Bot API;
- автопостинг новых публикаций из публичных RSS- и Atom-лент в собственный канал;
- автопостинг новых публикаций из публичных групп VK через официальный VK API, с фильтром по ключевым словам и ссылкой на оригинальную публикацию;
- автопостинг новых публикаций из публичных групп VK через официальный VK API, с фильтром по ключевым словам и ссылкой на оригинальную публикацию;
- общие карточки профилей в чатах, донаты звёздами и жалобы на каналы;
- оформление на уровне канала, доступное создателю и назначенным администраторам, без изменения личной темы посетителей;
- приватный список подписчиков канала: обычный подписчик видит только общий счётчик, а создатель и администраторы управляют участниками;
- админка для лимитов, премиума, звёзд, рекомендаций, акций, статусов и демо-накрутки счётчиков.

## Важно

Это локальная демо-версия. Все данные хранятся в файле `minigram.sqlite3` рядом с проектом.

### Коды подтверждения e-mail

Для регистрации и восстановления пароля используется привязанный e-mail. Уже созданные аккаунты сохраняют вход по прежнему username и паролю.

Для реальной доставки задайте переменные окружения перед запуском:

```bash
SMTP_HOST=smtp.example.com SMTP_PORT=587 SMTP_USERNAME=mailbox@example.com \
SMTP_PASSWORD=пароль_приложения SMTP_FROM=mailbox@example.com SMTP_USE_SSL=false \
python3 server.py
```

Для e-mail настройте SMTP: почта для домена в Reg.ru предоставляет такие параметры. Для порта 587 укажите `SMTP_USE_SSL=false` (STARTTLS); для порта 465 — `SMTP_USE_SSL=true`. На публичном сервере без SMTP коды не выводятся в журнал и не возвращаются API или браузеру: пользователь увидит понятное сообщение, что доставка ещё не настроена.

### Оплата звёзд через ЮKassa

Покупка звёзд создаётся только сервером. Секретный ключ ЮKassa нельзя передавать браузеру, добавлять в Git или отправлять в чат. После оплаты сервер дополнительно запрашивает её статус через API ЮKassa и только затем начисляет звёзды; повторная проверка того же платежа не начислит их второй раз.

Для начала создайте тестовый магазин в кабинете ЮKassa и получите его `shopId` и секретный ключ. В терминале на компьютере, где запущен сервер, перезапустите его с этими переменными (подставьте значения самостоятельно):

```bash
YOOKASSA_SHOP_ID=ваш_shop_id \
YOOKASSA_SECRET_KEY=ваш_секретный_ключ \
YOOKASSA_RETURN_URL=http://localhost:8000 \
python3 server.py
```

После запуска в разделе «Звёзды» появятся пакеты оплаты. По умолчанию это 100 звёзд за 99.00 ₽, 550 за 449.00 ₽ и 1200 за 899.00 ₽. Перед реальным запуском цены можно заменить одной переменной, например:

```bash
YOOKASSA_STAR_PACKAGES='[{"id":"stars-100","stars":100,"price":"99.00"},{"id":"stars-500","stars":500,"price":"399.00"}]'
```

Для рабочего режима укажите публичный HTTPS-адрес сайта в `YOOKASSA_RETURN_URL`, например `https://chat-pro-ru.space`. В кабинете ЮKassa добавьте уведомление `payment.succeeded` с URL `https://chat-pro-ru.space/api/yookassa/webhook`: сервер повторно сверит платёж через API ЮKassa, поэтому звёзды начислятся и если пользователь закроет страницу сразу после оплаты. Тестовый режим ЮKassa предназначен для проверки сценария; при приёме реальных платежей отдельно настройте уведомления и чеки в соответствии с требованиями ЮKassa и 54-ФЗ.

Звонки используют WebRTC. Для их проверки откройте приложение в двух разных браузерах или профилях браузера, войдите под разными аккаунтами и создайте личный чат. Оба устройства должны иметь доступ к одному серверу; при запуске на другом устройстве укажите IP компьютера вместо `localhost`.

## Установка на телефон

Это PWA-приложение. Отдельные App Store/TestFlight и Google Play/APK сборки требуют аккаунтов Apple/Google и отдельной сборки. Сейчас установка идёт с сайта:

- iOS: откройте `https://chat-pro-ru.space` в Safari → кнопка «Поделиться» → «На экран Домой».
- Android: откройте `https://chat-pro-ru.space` в Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

Функция накрутки подписчиков/просмотров/реакций работает только внутри этой локальной базы приложения и не влияет на реальные Telegram, VK или сайты.

## Импорт из Telegram

Создатель канала может открыть его профиль и выбрать «Импорт из Telegram». Для работы потребуются:

- токен Telegram-бота;
- исходный канал по `@username` или числовому ID;
- права администратора у бота в исходном канале;
- выключенный webhook у бота: импорт использует `getUpdates`.

После подключения импортируются только новые события `channel_post`; история публикаций Telegram не переносится. Токен хранится только в локальной SQLite-базе сервера и не возвращается приложению или админке.

## Автопостинг из RSS

Создатель канала может открыть его профиль и выбрать «Автопостинг из RSS». Можно подключить до 10 публичных RSS- или Atom-лент к одному каналу. Сервер проверяет каждый источник примерно раз в 5 минут и публикует только новые записи; элементы, уже находившиеся в ленте при подключении, не переносятся. Для новых постов сервер импортирует главную картинку из RSS или метатега страницы публикации, если она доступна. Один канал может иметь один источник Telegram и до 10 RSS-источников одновременно. Для проверки используйте ленту Ленты.ру: <https://lenta.ru/rss/top7>.

## Автопостинг из VK

Создатель канала может подключить до 10 публичных групп VK через «Настройки канала» → «Автопостинг из VK». Нужны ссылка вида `https://vk.com/имя_группы` и личный токен VK API с доступом к чтению стены публичных групп. Источник проверяется примерно раз в 5 минут; уже существующие посты не импортируются. Можно указать ключевые слова по одному на строку: тогда импортируется новый пост, содержащий хотя бы одно слово. В каждой импортированной публикации отображается ссылка на оригинал в VK. Токен хранится только в локальной SQLite-базе и не возвращается в интерфейс.
